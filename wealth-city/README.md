# Wealth City

A single-file 3D web app (Three.js r128) that turns a monthly SIP into a growing night city, with goal buildings, market events, time travel, Hindi/English and WhatsApp lead capture.

## Set up for an advisor
Open `index.html` and edit the `ADVISOR` block at the top of the script: name, firm, ARN, WhatsApp number (country code first, digits only), city.

Returns (8/10/12%), FD and savings rates, and goal costs/inflation are illustrative assumptions in the `ASSUME` and `GOALS` blocks. Review them before sharing with clients.

Mutual fund investments are subject to market risks. Read all scheme related documents carefully.
